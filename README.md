## 📌 项目概述

面向制鞋产线自动化涂胶需求，实现个性化鞋型鞋底/鞋面的自动识别与涂胶轨迹导引。从 RGB-D 图像输入到带位姿信息的涂胶轨迹输出，全链路自动化。

**核心挑战**：鞋底与背景颜色/纹理接近（伪装分割问题）、个性化鞋型种类多、点云轮廓需连续平滑、产线实时性要求。

**核心成果**：识别准确率 >99%，涂胶轨迹定位精度 ≤1mm，2项发明专利授权（第一/第二发明人），1篇论文在审（第一作者），独立打通"数据采集→算法研发→产线部署验证"全流程。

## 🏗️ 三阶段技术架构

```
阶段一：实例分割（感知）
  RGB-D鞋底图像 → 轻量分割模型 → 鞋底涂胶区域像素级mask

阶段二：三维重建与点云处理（重建）
  分割mask + 深度信息 → 涂胶区域点云 → 多平面投影 + 几何特征融合 → 连续平滑的三维轮廓

阶段三：轨迹提取与工程落地（轨迹）
  三维轮廓 → 几何分析 + 工艺参数 → 带位姿的涂胶轨迹 → 模型轻量化 → 产线部署
```

三阶段递进，每一步以上一步的输出为输入。核心方法学：**感知→重建→轨迹是递进关系，每一步的上游质量决定下游上限**——分割不准，点云再好也提取不出正确轮廓；点云不连续，轨迹算法再优也生成不了平滑路径。

## 🔬 技术详解

### 阶段一：RGB-D 伪装实例分割

**问题**：鞋底放在工作台上采集图像时，鞋底颜色与背景颜色可能接近，在 RGB 图像中边界模糊——这在计算机视觉中属于**伪装目标分割（Camouflaged Object Segmentation）**问题。

**解决方案**：引入深度信息辅助 RGB 分割。RGB 管"是什么"（纹理/颜色），深度管"在哪"（Z轴高度差）。

**模型设计**：
- **动态路由**：根据输入鞋型的尺度分布，动态选择特征传播路径。不同鞋型（运动鞋/皮鞋/靴子）的涂胶区域形状和尺度差异大，静态网络结构难以兼顾。
- **拓扑聚合**：利用鞋底轮廓的拓扑结构信息（闭合性、连通性）增强特征聚合。鞋底涂胶区域是一个连续闭合的环状结构，拓扑约束能帮助模型生成更完整的分割 mask。

### 阶段二：单视图三维重建与点云处理

**问题**：传统三维重建需要多视角图像，但产线上只有一台固定相机（单视图）。单视图重建的核心挑战是**深度歧义**。

**解决方案**：
- **协同编码架构**：可见光分支提取纹理/几何特征，激光/深度分支提取三维形貌特征，两个分支在编码阶段交互融合。
- **特征融合标定模块**：基于鞋底几何结构生成虚拟标定靶点，不需要物理标定板；通过深度学习迭代更新配准变换矩阵。
- **多平面投影 + 几何特征融合**：从不同方向对点云做切面，获取截面轮廓，融合后覆盖鞋底完整轮廓。
- **GAN 误差校正**：在曲率连续性与涂胶工艺间隙约束下生成修正轮廓，补全点云缺失部分。

### 阶段三：轨迹提取与产线部署

**问题**：三维轮廓是"线"，涂胶轨迹是"带位姿的点序列"——机器人需要每个轨迹点的 (x,y,z) 位置和法向量（姿态）。

**解决方案**：
- 曲率自适应离散化（曲率大处密、曲率小处疏）
- 法向量计算（涂胶枪姿态控制）
- 工艺参数注入（涂胶宽度、间距、速度）
- 坐标变换（相机坐标系→机器人坐标系）
- 模型轻量化 + 全链路推理优化

**产线部署**：独立打通"数据采集→算法研发→产线部署验证"全流程，实验室到产线的精度衰减通过 RGB-D 融合 + 多平面投影冗余 + GAN 误差校正解决。
